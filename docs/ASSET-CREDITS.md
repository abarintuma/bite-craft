# Image sources

Sanyu Judith’s default photograph and the assignment/Figma reference screenshots were provided by the project owner and included as requested. The default photograph is bundled as `assets/sanyu-judith.jpg`.

Food and kitchen photography is from Unsplash, downloaded for a self-contained demonstration. Images are representative, not photographs of a real BiteCraft restaurant’s menu. Some category photographs are reused across dishes. No photographer names were supplied by the image endpoints; the source IDs below preserve traceability.
